
# Cognifyz Task Manager – File Storage

## About the Project
A Python-based Task Manager with File Storage developed as part of the Cognifyz Technologies Software Development Internship.

## Features
- Create tasks
- View saved tasks
- Update tasks
- Delete tasks
- Store tasks in a file
- Retrieve tasks when the program restarts

## Technologies Used
- Python
- File Handling
- CRUD Operations
- Functions
- Conditional Statements

## How to Run

```bash
python task_manager_file.py
```
